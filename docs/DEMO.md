# Demo and preview

Use synthetic or permission-cleared media for public screenshots and GIFs. Do not upload a user's original video by default.

Recommended release assets:

- `GWR-Fast-Watermark-Remover-windows.zip` — portable Windows build
- `SHA256SUMS.txt` — checksum for the portable ZIP
- `demo-before.png` and `demo-after.png` — same frame, with a small test mark
- `demo.gif` — 10–20 second UI walkthrough

The README includes [`demo.svg`](demo.svg), a synthetic before/after preview.
For a real walkthrough, use permission-cleared media and show this sequence:

1. Drop a folder or select several image/video files.
2. Click **Tự động tìm Logo** and confirm the red ROI.
3. Click **Xem trước kết quả** to compare the first frame without writing a file.
4. Start the batch and, if needed, use **Dừng** for a safe cancellation.
5. Open the sibling `Template` folder and verify the output.

Never record or publish private source paths, faces, audio, or media that you do
not have permission to redistribute.
