# Code of Conduct

We want GWR Fast Watermark Remover to be a useful, welcoming open-source
project. Contributors are expected to communicate respectfully, assume good
intent, and focus feedback on the work rather than on people.

Unacceptable behaviour includes harassment, discrimination, threats, doxxing,
deliberate sharing of private media, and publishing credentials or personal
information. Project maintainers may edit or remove comments, close issues, or
restrict participation when this standard is not met.

Report a conduct concern privately to the repository owner. Do not attach
private source media; describe the issue with a minimal synthetic example.
